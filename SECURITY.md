# Security

> **LANE:** Public security reporting  
> **IS:** Disclosure instructions and scope boundary  
> **IS NOT:** A security certification for AI systems using the harness  
> **FORBIDDEN CROSS-OVERS:** Publishing secrets or exploit details in an issue  
> **SOURCE OF TRUTH:** The repository security policy after publication  
> **GATE:** Sensitive reports use private GitHub security advisories

The harness is an operating pattern and reference skill. It does not provide a sandbox, identity provider, secret store, or authorization service.

Report suspected vulnerabilities through GitHub's private security-advisory flow. Do not include real credentials, production identifiers, private prompts, or user data in public issues.
