# Cybernetic model

> **LANE:** Public explanatory documentation  
> **IS:** A precise interpretation of the harness as a feedback-control architecture  
> **IS NOT:** A claim that James invented cybernetics or that the analogy proves effectiveness  
> **FORBIDDEN CROSS-OVERS:** Private operational examples and unsupported outcome claims  
> **SOURCE OF TRUTH:** The public harness behavior and cited cybernetics literature  
> **GATE:** Keep the framing subordinate to observable behavior

The harness is cybernetic in structure because it governs action through feedback:

| Cybernetic element | Harness implementation |
|---|---|
| Goal or setpoint | Project contract and intended outcome |
| Sensor | Preflight, status inspection, tests, and rendered-state checks |
| Comparator | Verification of actual state against authoritative desired state |
| Controller | Resolver and action boundary |
| Actuator | The bounded tool or agent action |
| Feedback | Test output, external state, and completion evidence |
| Memory | Contracts, receipts, and maintained guidance |
| Adaptation | Promotion of demonstrated recurring failures into narrow controls |
| Human governor | Explicit authority for consequential actions |

The loop is:

```text
Sense → compare → decide → act → verify → record → adapt
```

The public claim is intentionally limited: this architecture applies feedback-control principles to AI-assisted work. It does not establish that every implementation is safe, stable, or effective.
