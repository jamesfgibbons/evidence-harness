Evidence Harness is the public form of the personal control layer I use around AI-assisted work in my own stack.

This preview includes:

- selective task routing, including an explicit load-nothing path;
- authority and action classification;
- evidence-gated completion language;
- an installable directory-based skill;
- a completion-receipt schema and standard-library helper;
- a synthetic context-mismatch demonstration;
- conformance, packaging, and public-hygiene checks.

The preview intentionally excludes private product rules, production integrations, credentials, prompts, traces, runbooks, and incident evidence.

## Install

Download the release archive and copy `evidence-harness/` into the skills directory supported by your agent environment.
